# Kunj Sodhi — Portfolio Website

> **AI Engineering · Full-Stack Development · Creative Video Editing**

A high-performance, cinematic personal portfolio built for **Kunj Sodhi**, featuring interactive 3D chapter frames, an eye-tracking character gaze engine, live project simulations, and a DaVinci Resolve-inspired studio monitor.

---

## ⚡ Highlights & Features

- **Dark Cinematic Studio Aesthetic**: Deep Obsidian canvas (`#090A0D`), Electric Cobalt, Warm Amber accents, and 35mm film grain texture.
- **Dynamic Eye-Tracking Engine**: Standalone illustrated portrait with an isolated eye gaze engine where only the pupils glide across the lenses to track the user's cursor with real-time degree telemetry.
- **3D Story Chapter Transitions**: Sections structured into immersive 3D chapters (*Act 01: Perspective*, *Act 02: Verified Builds*, *Act 03: Toolkit*, *Act 04: The Timeline & Reel*, *Act 05: Diagnostics*, *Act 06: Transmission Dossier*).
- **Interactive Project Sandboxes**:
  - **MediTriage AI**: Interactive clinical triage simulator with live condition switches and vital telemetry.
  - **RideHub**: Interactive cab aggregator comparison simulator with dynamic surge, price, and ETA calculations.
- **DaVinci Resolve Studio Monitor**: Studio video editing preview monitor with live timecode, active audio VU meters, and interactive LUT switcher (Rec.709, LOG Raw, Kodachrome).
- **Continuous Kinetic Marquees**: Dual ambient ribbons with zero seam clipping.

---

## 🛠️ Tech Stack

- **Core**: Vanilla JavaScript (ES6+), Semantic HTML5
- **Styling**: Modular Modern CSS (CSS Grid, Flexbox, Custom Properties, Glassmorphism)
- **Tooling**: [Vite](https://vitejs.dev/)
- **Typography**: Instrument Serif, Newsreader, Libre Franklin, IBM Plex Mono, Permanent Marker

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `pnpm`

### Installation

```bash
# Clone the repository
git clone https://github.com/Kunj272006/Portfolio.git

# Navigate to project directory
cd Portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
```

The output bundle will be generated in `dist/`.
